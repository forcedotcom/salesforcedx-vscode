# W-24093793: Migrate LWC off vsce-bundled-extension to vsce package

## Context

`packages/salesforcedx-vscode-lwc/package.json` packages release and prerelease VSIX files through `scripts/vsce-bundled-extension.ts`. Migrate only the LWC extension to direct `vsce package` commands, removing its dependency on the legacy bundled-extension packaging flow.

## Phases

### 1. Use direct VSCE packaging

- Change `packages/salesforcedx-vscode-lwc/package.json`:
  - replace `vscode:package:legacy` with `vscode:package`
  - run `vsce package --allow-package-all-secrets`
  - depend only on `vscode:bundle`
  - declare package inputs and `*.vsix` output for Wireit
  - replace `vscode:package:legacy:prerelease` with `vscode:package:prerelease`
  - run `vsce package --allow-package-all-secrets --pre-release`
  - depend only on `vscode:bundle`
  - remove the `VSCE_PRE_RELEASE` environment switch
- Commit: `feat(lwc): migrate packaging to vsce`

## Skills to apply

- `packageJson`: follow repository packaging and Wireit conventions; remove legacy packaging rather than adding another wrapper.
- `wireit`: define direct package commands, dependencies, inputs, and outputs consistently.
- `verification`: verify the focused packaging change and repository checks.

## Verification

1. Run `npm install` from the repository root.
2. Run `npm run vscode:package -w salesforcedx-vscode-lwc`.
3. Run `npm run vscode:package:prerelease -w salesforcedx-vscode-lwc`.
4. Run the repository compile, lint, test, bundle, and Knip checks through the standard stop hook.
5. Inspect both generated LWC VSIX files to confirm packaging succeeds and expected extension files are present.
