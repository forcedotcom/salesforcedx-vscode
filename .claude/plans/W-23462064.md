# W-23462064

## Context

Migrate the Visualforce markup language server from the repository-owned `@salesforce/salesforcedx-visualforce-markup-language-server` fork to the npm `vscode-html-languageservice` package. Preserve current Visualforce completion, hover, highlighting, symbols, links, formatting, scanning, mixed-case tag handling, and embedded CSS/JavaScript behavior while removing the fork and its build graph.

## Phases

### 1. Consolidate parity coverage

Commit: `test: consolidate Visualforce markup parity coverage`

- Move/adapt the fork’s Jest coverage into `packages/salesforcedx-visualforce-language-server/test/jest/` while it still targets the current service.
- Cover the existing completion, hover, highlighting, symbols, links, formatting, parser/scanner, Visualforce metadata, and embedded-language behavior that the npm service must preserve.

### 2. Replace the fork and remove it

Commit: `feat: migrate Visualforce markup to vscode-html-languageservice`

- Add `vscode-html-languageservice` to `packages/salesforcedx-visualforce-language-server/package.json`; remove the fork dependency and Wireit compile dependency.
- Convert `packages/salesforcedx-visualforce-markup-language-server/src/parser/visualforceTags.ts` metadata into an npm-service `IHTMLDataProvider` owned by `packages/salesforcedx-visualforce-language-server/src/modes/`.
- Update `visualforceServer.ts`, `modes/htmlMode.ts`, `modes/languageModes.ts`, `modes/embeddedSupport.ts`, and affected Jest imports to use `vscode-html-languageservice`; configure the service with the Visualforce data provider.
- Change only the consolidated tests’ imports and renamed API references needed to exercise the npm service; keep their parity assertions unchanged.
- Delete `packages/salesforcedx-visualforce-markup-language-server/`.
- Remove the deleted workspace package from root `package.json` compile/lint/test dependencies and from `packages/salesforcedx-vscode-visualforce/package.json` devDependencies/Wireit dependencies.
- Regenerate `package-lock.json` with the workspace package removed and the direct npm dependency recorded.
