# W-22888208 — Playwright `no-wait-for-timeout` and `no-wait-for-selector`

## Context

Enable `playwright/no-wait-for-timeout` and `playwright/no-wait-for-selector` for the existing Playwright lint scope. Replace fixed sleeps and `page.waitForSelector()` calls with locators, assertions, and polling tied to the state each call already intends to await. This makes failures describe the missing state and avoids timing-dependent waits.
