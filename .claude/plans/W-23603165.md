# W-23603165: Validate project login URL

## Context

- `authParamsGatherer.ts:162-167` returns `sfdcLoginUrl` directly from `sfdx-project.json`; `pickInstanceUrl` then exposes it as **Project Default** and can return it as `loginUrl` (`:93-116`).
- `orgLoginWeb.ts:31-36` interpolates `loginUrl` into the quoted `sf org login web --instance-url` command passed to `TerminalService.simpleExec`.
- User-entered instance URLs use `validateUrl` (`authParamsGatherer.ts:20-25,61-63,104-109`), but the project value bypasses it.
- Scope: validate only project-derived `sfdcLoginUrl`. Preserve Production, Sandbox, Custom, absent-project-value behavior, and user-entered URL behavior.

## Approach

Validate at the `getProjectLoginUrl` trust boundary before `buildOrgTypes` receives the value. Require the raw configured value to pass the existing shell-safe `validateUrl` constraint, parse it with the platform `URL` constructor, and accept only `http:`/`https:` because `orgLoginWeb.ts` interpolates the result into a shell command. Return the parsed URL's normalized `href` when valid. For malformed, unsupported-protocol, or shell-unsafe values, show one localized non-blocking warning and return `undefined`; **Project Default** is then omitted without changing the other choices.

## Phases

### Phase 1: Validate and warn at project-config read

- Update `packages/salesforcedx-vscode-org/src/commands/auth/authParamsGatherer.ts` to distinguish absent configuration from invalid configuration.
- Check the raw `sfdcLoginUrl` with `validateUrl`, then parse it without allowing constructor failures into the Effect error channel and require `http:`/`https:`.
- Return normalized `href` for accepted values. Return `undefined` for rejected values so `buildOrgTypes` omits **Project Default**.
- Show a direct, localized, fire-and-forget `vscode.window.showWarningMessage` once per rejected read; do not warn when the key is absent.
- Add the consumed warning key to `packages/salesforcedx-vscode-org/src/messages/i18n.ts` in the same phase because `nls.localize` keys are typed. Include the rejected value via `%s` and explain that Project Default is unavailable.

### Phase 2: Add focused regression coverage

- Extend `packages/salesforcedx-vscode-org/test/jest/commands/auth/authParamsGatherer.test.ts`; provide `ProjectService` through the existing services layer and spy on QuickPick and warning surfaces.
- Cover valid `http:` and `https:` values: normalized URL appears in the **Project Default** detail and is returned when selected.
- Cover malformed input, unsupported protocols, and a URL-shaped shell payload: **Project Default** is absent, one localized warning is shown, and the flow can only select a safe remaining URL.
- Cover missing `sfdcLoginUrl`: no warning and only Production, Sandbox, and Custom remain.
