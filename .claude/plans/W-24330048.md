# W-24330048

Manual test plan section on PR open.

## Context

- On `pull_request` `opened` and `synchronize`, a GitHub Action writes one Manual test plan block into the PR body.
- Shape like changelog body (workflow + Effect script + judgment skill). New script. Do not copy `scripts/changelogBody/changelogBody.mts` (`packageSet`, section renderer, commit-range model stay there).
- Checkout PR head SHA, `fetch-depth: 0`. Script loads the judgment skill from the base branch, prompts with `git diff origin/<base>...HEAD`. `Agent.prompt` tools `read`, `grep`, `glob`, `ls`; `local.cwd` is the checkout. Parses JSON against `Judgment`. Each `watch-video` item: spec is a `test/playwright` `.spec.ts` that exists, workflow name is a leaf `*E2E.yml` `name`, job is a job key in that file. One retry with the error. Splices one marked block. Rest of the body stays.
- Missing `IDEE_CURSOR_API_KEY` skips the job. Cursor error, a second validation failure, or missing skill ref: log, exit 0, body unchanged. Not a merge gate.
- Body edit uses `github.token` (`pull-requests: write`). Not `secrets.IDEE_GH_TOKEN`. A PAT would re-fire `validatePR.yml` `edited` (`pr-validation`, `code-quality`, `check-effect-diagnostics` have no `action != 'edited'` guard). `GITHUB_TOKEN` does not ([Triggering a workflow from a workflow](https://docs.github.com/en/actions/using-workflows/triggering-a-workflow#triggering-a-workflow-from-a-workflow)).
- Draft-time `## Test plan` leaves `.claude/workflows/auto-build-wi.js` `draftPrPrompt`.

## Phases

### 1. `feat(ci): add manual test plan judgment skill`

`.cursor/skills/manual-test-plan-judgment/SKILL.md`

- Frontmatter like changelog-judgment. `disable-model-invocation: true`. Only caller: the manual test plan script.
- Reply: one JSON object, no fences.
- Schema the script accepts:
  - `{ "kind": "nothing" }` renders `Nothing worth manually testing.`
  - `{ "kind": "checklist", "items": [ ... ] }` with one or more items:
    - `{ "kind": "watch-video", "spec": string, "workflow": string, "job": string }`
    - `{ "kind": "manual", "step": string }`
- `job` is a job key that workflow file defines (`e2e-web`, `e2e-desktop`, `e2e-desktop-lsp`, `e2e-desktop-run-tests`, `e2e-desktop-debug-tests`, `e2e-conflicts-web`, `e2e-conflicts-desktop`, `code-builder-e2e`, …). Not the union `e2e-web | e2e-desktop`.
- Judgment traces what the change does for the end user, including a diff in services or a language server.
- `nothing` when there is no extension surface, or the behavior is already asserted. Language servers are on-screen.
- An assertion clears only what it asserts. Command-exists, UI-opened, and no-critical-errors do not clear a surface.
- Visual check (manual item) when e2e does not assert the surface, including refactors.
- Watch-video item: repo-relative `test/playwright` `.spec.ts` that exists, workflow `name` of a leaf `*E2E.yml`, job key in that file. Artifact URL stays out. Script rejects a bad item and sends the error back once.
- Checklist lines render as GitHub task items. Manual steps are the other checkbox.

### 2. `feat(ci): splice a manual test plan from the PR diff`

New `scripts/manualTestPlan/` (not a fork of `changelogBody.mts`). No fact gatherer. Agent reads the checkout.

Root `package.json` depends on `@cursor/sdk`. Script imports `@salesforce/effect-octokit`. No nested `scripts/manualTestPlan/package.json` or lockfile. No `npm ci`.

`manualTestPlan.mts`: `Agent.prompt` (`tools: ['read', 'grep', 'glob', 'ls']`, `model: { id: 'auto' }`, `local.cwd` = checkout, `apiKey` from `CURSOR_API_KEY`) and `Schema.parseJson(Judgment)`. Leave `packageSet` and the section renderer in `changelogBody.mts`.

Skill text: `git show origin/<base>:.cursor/skills/manual-test-plan-judgment/SKILL.md`. Base ref is `actionsEnvironment` `GITHUB_BASE_REF` (Actions sets it on `pull_request`), then `git fetch origin <base>`. Ref must match `^[A-Za-z0-9._/-]+$` with no `..` segment. Missing skill ref: log, exit 0, body unchanged.

Prompt: skill text plus `git diff origin/<base>...HEAD`.

Parse the reply as `Judgment`. Then each `watch-video` item:

- `spec`: repo-relative path, a `test/playwright` `.spec.ts` (no leading `/`, no `..`) that exists in the checkout
- `workflow`: `name:` of a leaf `.github/workflows/*E2E.yml` (not `e2e.yml`, `playwrightE2EFullSuite.yml`, `rerunPushE2E.yml`)
- `job`: a job key in that file

Schema failure (`items` is `NonEmptyArray`) or a watch-video problem: one retry. Correction is the error plus the previous reply. A second failure, or a Cursor error: log, exit 0, body unchanged.

Render:

- markers `<!-- manual-test-plan -->` … `<!-- /manual-test-plan -->`
- heading `## Manual test plan`
- `nothing` → `Nothing worth manually testing.`
- watch-video → `- [ ] Watch video: \`<spec>\` in \`<workflow>\` (\`<job>\`)`
- manual → `- [ ] <step>`

Markers present: replace that block. Markers absent: append it. Every other byte of the body stays.

Write back with `GitHub.pullBody` and `GitHub.updatePullBody` on `packages/effect-octokit`. Direct run provides `GitHub.Default`. Token is `GITHUB_TOKEN` (`github.token`). Re-read the body immediately before the edit.

Cursor error, a second schema or watch-video failure, or missing skill ref: log, exit 0, do not edit the body.

### 3. `ci: write manual test plan on PR open and push`

`.github/workflows/manual-test-plan.yml`

- `on.pull_request.types`: `opened`, `synchronize`.
- `concurrency`: `group: manual-test-plan-${{ github.event.pull_request.number }}`, `cancel-in-progress: false` (same serialization as `docOnlyAutoMerge.yml`).
- Secret check job sets `has_key` from `secrets.IDEE_CURSOR_API_KEY`. Body job `if: has_key == 'true'` so a missing key skips that job.
- Body job: checkout `github.event.pull_request.head.sha`, `fetch-depth: 0`. `setup-pnpm` (`node-version: 24`). `pnpm --filter @salesforce/effect-octokit compile`. Run `node scripts/manualTestPlan/manualTestPlan.mts`.
- Env: `CURSOR_API_KEY`, `GITHUB_TOKEN: ${{ github.token }}`, `GITHUB_EVENT_PATH: ${{ github.event_path }}`, `GITHUB_REPOSITORY: ${{ github.repository }}`. Pull number from `GITHUB_EVENT_PATH` (`pull_request.number`). Base ref from `actionsEnvironment` `GITHUB_BASE_REF`. No `IDEE_GH_TOKEN`, `GH_TOKEN`, `PR_NUMBER`, or `BASE_REF`.
- `permissions`: `contents: read`, `pull-requests: write`.
- Workflow stays off required status checks.
