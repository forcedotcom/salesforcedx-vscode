# W-24154016

## Context

Add a shared `QueryService` to `salesforcedx-vscode-services` with the same query contract as `sf-effect`. Use it for extension SOQL and Tooling API queries instead of calling `Connection.query` or `connection.tooling.query` directly. This centralizes Effect-based query execution and exposes it through the existing Services extension API.
