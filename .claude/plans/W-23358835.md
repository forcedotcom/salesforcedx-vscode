# W-23358835 — Adopt Predicate.isError across effect packages

## Context

- Replace the `x instanceof Error` guard w/ `isError(x)` from `effect/Predicate`.
- Scope: packages ALREADY depending on `effect` only. ~65 non-test hits, 13 pkgs.
- Import style: `import { isError } from 'effect/Predicate'` (matches existing `isString`/`isNotUndefined` convention). WI claim "no Predicate.* usage" is stale — codebase uses named `effect/Predicate` imports already; use that, NOT namespace `Predicate.isError`.
- `isError` is a drop-in refinement `(input: unknown) => input is Error`, so it replaces the guard in BOTH shapes:
  - **Ternary** (~50 hits): `e instanceof Error ? e.message : String(e)` → `isError(e) ? e.message : String(e)`; also `? e : new Error(String(e))`, `? e : undefined`, `? e.stack : ...`, `? {cause:e} : ...` — same guard swap.
  - **Boolean guard** (~15 hits): `if (error instanceof Error)` → `if (isError(error))`; `if (!(error instanceof Error))` → `if (!isError(error))`; `} else if (error instanceof Error)` → `} else if (isError(error))`; compound `error instanceof Error && 'code' in error` → `isError(error) && 'code' in error`; nested `error.error instanceof Error` → `isError(error.error)`.
- Verified: `effect/Predicate` exports `isError: (input: unknown) => input is Error` (node_modules/effect/dist/dts/Predicate.d.ts:906).
