## Phases

### 1. Toast from the builder catch

`fix: toast when SOQL Builder Run Query fails`

`packages/salesforcedx-vscode-soql/src/messages/i18n.ts` — add toast key. Sentence case, terminal `.`, one `%s` for the squashed message (`isError` message or `String`). `%s`, not `%n`. No `package.nls.json` equivalent. Do not edit `error_run_soql_query` (`ERROR: We can't run the SOQL query. %s`). Channel append keeps that key. `i18n.ja.ts` is `Partial` — no ja entry.

`error_run_soql_query_toast: "We can't run the SOQL query. %s."`

`packages/salesforcedx-vscode-soql/src/editor/soqlEditorInstance.ts` — `run_query` `catchAllCause` (around the `appendToChannel` of `error_run_soql_query`):

- `const err = Cause.squash(cause)` (read ≥2×). `const detail = isError(err) ? err.message : String(err)` (channel + toast).
- Channel stays `nls.localize('error_run_soql_query', detail)`. Toast uses the new key. Not one shared localize.
- `Effect.sync` is a step of the effect `catchAllCause` returns. Void the Thenable inside the callback. `Effect.sync` only. No `Effect.promise`, no yield of the Thenable.

```ts
appendToChannel(nls.localize('error_run_soql_query', detail)).pipe(
  Effect.tap(() =>
    Effect.sync(() => {
      void vscode.window.showErrorMessage(nls.localize('error_run_soql_query_toast', detail));
    })
  ),
  Effect.andThen(runQueryDone())
)
```

- Keep the channel append and `runQueryDone()` after it.
- Leave `get_query_plan` unchanged.
