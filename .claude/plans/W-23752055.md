# W-23752055 — Upgrade SOQL results viewer to Tabulator 6.5.0

## Context

The SOQL query-results webview vendors Tabulator 4.8.1 JavaScript and CSS in `packages/salesforcedx-vscode-soql/src/soql-data-view/`. Replace those assets with Tabulator 6.5.0 and update the existing viewer integration for the 6.5 API while preserving its current result rendering, pagination, nested tables, resizing, state restoration, and export protocol.

## Phases

### 1. Upgrade the query-results viewer

Commit: `feat(soql): upgrade query results viewer to Tabulator 6.5.0`

- Replace the official vendored distribution files:
  - `packages/salesforcedx-vscode-soql/src/soql-data-view/tabulator.min.js`
  - `packages/salesforcedx-vscode-soql/src/soql-data-view/tabulator.min.css`
- Update `packages/salesforcedx-vscode-soql/src/soql-data-view/queryDataViewController.js` to use Tabulator 6.5-supported options and DOM behavior; retain the existing table data and VS Code message contracts.
- Update the Tabulator documentation/version reference in `packages/salesforcedx-vscode-soql/src/soql-data-view/queryDataView.css`.
- Update `packages/salesforcedx-vscode-soql/test/jest/queryDataView/queryDataViewController.test.ts` for the 6.5 configuration and retain coverage of restoration, rendering, updates, exports, destruction, and resizing.
- Update the measured vendor-asset baseline and budget in `packages/salesforcedx-vscode-soql/test/baselines/soql-ui-bundles.json` for the checked-in 6.5.0 distribution.
