# W-23795174 — Fix doc-only CI routing and auto-merge scan gate

## Context

Doc-only set is the allowlist in `.github/workflows/docOnlyAutoMerge.yml` (header + `allow` regex): `CONTEXT.md`, `CONTEXT-MAP.md`, `docs/**/*.md`, `.claude/**/*.md`. Not `.claude/**/*.js`.

Required workflows `paths-ignore` a wider set (`.github/workflows/validatePR.yml` and the same block on E2E / `testCommitExceptMain.yml`): `.claude/**`, `.cursor/**`, `contributing/**`, `CONTRIBUTING.md`, `docs/**`, `**/README*`, `SECURITY*`, `CODE_OF_CONDUCT*`, `CHANGELOG*` (validatePR). A PR whose files all match that ignore never posts `pr-validation` / `code-quality` (`docOnlyAutoMerge.yml` lines 8–9) and does not match the auto-merge `paths` trigger, so it neither runs required CI nor auto-merges.

Scan gate (`docOnlyAutoMerge.yml` “Gate — security scans present and settled”) requires both `SAST` and `Credential Scanning Analysis` present and settled, then on the 30 min timeout sets `ok=true` and the squash-merge step runs anyway (lines 156–159).

Approach: paths-ignore equals the auto-merge trigger globs only. Timeout does not merge.
