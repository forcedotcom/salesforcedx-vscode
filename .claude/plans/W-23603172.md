# W-23603172

## Context

The changelog path places a release branch name inside shell command strings in `scripts/create-release-notes.ts` and `scripts/change-log-generator-utils.ts`. A crafted branch name can therefore execute commands in changelog CI and expose its credentials. Prevent shell interpretation by invoking Git with argument arrays after the existing release-branch validation.

## Phases

1. **Make changelog Git execution shell-free**
   - Replace release-branch interpolation in `scripts/create-release-notes.ts` and `scripts/change-log-generator-utils.ts` with direct Git executable calls using separate arguments.
   - Preserve existing changelog behavior and release-branch validation.
   - Add focused tests proving a shell-metacharacter branch value is rejected or passed only as a literal Git argument, while a valid release branch still works.
   - Commit: `fix: prevent changelog release branch shell injection`

## Skills to apply

- `typescript` — repository TypeScript and test conventions.
- `verification` — required checks, including GitHub Actions validation only if workflow YAML changes become necessary.
