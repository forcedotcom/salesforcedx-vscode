# W-24249696: Delete old plan files weekly

## Context

- Weekly cleanup for tracked `.claude/plans/*.md` files
- Delete plans with no Git change during the previous 14 days
- GitHub Actions schedule + `workflow_dispatch`

## Phases

### 1. Add plan cleanup workflow

**Commit:** `chore: delete plan files older than 14 days weekly`

- Add `.github/workflows/cleanupOldPlanFiles.yml`
- Weekly schedule + `workflow_dispatch`; manual `base-ref` input defaulting to `develop` for controlled verification
- Workflow concurrency: `cleanup-old-plan-files`, `cancel-in-progress: false`
- Job permissions: `contents: write`, `pull-requests: write`
- `actions/checkout@v4`: selected base ref + `fetch-depth: 0`
- Pre-selection guard: fail unless `git rev-parse --is-shallow-repository` returns `false`
- UTC cutoff: 14 days before run time
- One history walk, not one process per plan:
  - `LC_ALL=C` for both sorted sets
  - tracked set: sorted NUL-delimited output from `git ls-files -z -- '.claude/plans/*.md'`
  - recent set: sorted unique NUL-delimited paths from one `git log --since="@$cutoff" --name-only --format= -z --diff-filter=ACMR -- '.claude/plans/*.md'`
  - deletion set: tracked set minus recent set via NUL-safe `comm`
- `set -euo pipefail`; shallow or failed history read = failed job, not an empty set
- Empty deletion set: skip `git rm`; still run PR action to close/delete any obsolete fixed-branch PR
- Delete only the computed NUL-delimited paths via `git rm --pathspec-from-file=... --pathspec-file-nul`
- Assert deleted paths exactly match the computed set; any other worktree change = failed job
- Create/update PR via `peter-evans/create-pull-request@v8`:
  - base: selected base ref
  - branch: `automated/cleanup-old-plan-files` for `develop`; fixed `automated/cleanup-old-plan-files-verification` for manual fixture runs
  - `add-paths: .claude/plans/*.md`; commit only computed deletions
  - fixed branch update when its PR exists; no duplicate PR
  - `delete-branch: true`
  - no diff against base: no commit, push, branch, or PR
  - token: `${{ secrets.GITHUB_TOKEN }}`; API permission denial fails the job without fallback or `continue-on-error`
- Workflow `gh`: none; any later `gh` call requires `GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}`

## Skills to apply

- `verification`: repository action checks + controlled workflow run
- `concise`: direct names, comments, and shell logic

## Verification

1. `WIREIT_CACHE=none npm install`
2. `WIREIT_CACHE=none npm run check:actions`
3. Controlled behavior run after the workflow reaches the default branch:
   - Create `automation/verify-cleanup-old-plan-files` from `develop`
   - Add `cleanup-verification-old.md`; commit with author and committer dates 15 days ago
   - Add `cleanup-verification-recent.md`; commit with current UTC dates
   - Push fixture branch
   - `GH_TOKEN=... gh workflow run cleanupOldPlanFiles.yml --ref develop -f base-ref=automation/verify-cleanup-old-plan-files`
   - Get run ID via `GH_TOKEN=... gh run list --workflow cleanupOldPlanFiles.yml --event workflow_dispatch --branch develop --limit 1`
   - `GH_TOKEN=... gh run watch <run-id> --exit-status`
   - Use `GH_TOKEN=... gh pr list --head automated/cleanup-old-plan-files-verification --base automation/verify-cleanup-old-plan-files`; assert exactly 1 PR
   - Use `GH_TOKEN=... gh pr diff <pr-number> --name-only`; assert only `.claude/plans/cleanup-verification-old.md`
   - Repeat dispatch while PR remains open; assert same PR number, no duplicate
4. No-match run:
   - `GH_TOKEN=... gh pr close <pr-number> --delete-branch`
   - Update the old fixture on the fixture branch with a current UTC commit
   - Repeat dispatch + watch
   - Assert no verification PR and no `automated/cleanup-old-plan-files-verification` remote branch
5. Cleanup: `git push origin --delete automation/verify-cleanup-old-plan-files`; both fixtures removed with the branch
