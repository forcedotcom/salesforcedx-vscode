# W-23354940 — username param on getConnection + migrate determineConnectedStatusForNonScratchOrg

## Context
- `ConnectionService.getConnection()` (connectionService.ts L211-243) desktop path resolves username only from config `target-org`.
- Add optional `username?` param. Given → skip config `target-org` lookup, alias-resolve the given value, `connectionCache.get()` resolved username. Omitted → unchanged (~29 no-arg callers unaffected).
- Web path (L212-220, SettingsService) out of scope — unchanged.
- `maybeUpdateDefaultOrgRef(conn)` (L236) mutates global `defaultOrgRef`/`TargetOrgRef` — must reflect DEFAULT org only. Skip it when `username` explicitly passed.
- Migrate `determineConnectedStatusForNonScratchOrg` (orgUtil.ts L195-213) off `Org.create` + `org.refreshAuth()`.
- Confirmed (node_modules/@salesforce/core): `connectionCache.get`/`createDesktopConnection` = `AuthInfo.create` + `Connection.create`, no network. `Connection.refreshAuth` (org/connection.js L345-357) = live GET vs baseUrl → detects expired/revoked token. `Org.refreshAuth` (org/org.js L814-815) just delegates to `Connection.refreshAuth`. So `getConnection(username)` alone insufficient — MUST call `conn.refreshAuth()` after.
- Confirmed `getConnection` fails with 4 DISTINCT tagged errors (connectionService.ts): `NoTargetOrgConfiguredError` (L226), `FailedToResolveUsernameError` (L58, from alias resolve), `FailedToCreateAuthInfoError` (L98/L406), `FailedToCreateConnectionError` (L133). All 4 carry a `message` field. Effect `Schema.TaggedError` extends `Error` (Schema.js L5042 makeClass Base=YieldableError).

## Phases

### Phase 1 — add username param to getConnection
- connectionService.ts: `getConnection = Effect.fn('ConnectionService.getConnection')(function* (username?: string) {`

- After conn resolved: run `maybeUpdateDefaultOrgRef` fork ONLY when `username === undefined` (arbitrary org must not mutate `defaultOrgRef`/`TargetOrgRef`).
- Web path untouched (ignores param).
- commit: `feat(services): add optional username param to ConnectionService.getConnection - W-23354940`

### Phase 2 — migrate determineConnectedStatusForNonScratchOrg
- orgUtil.ts L195-213:
  - `const api = yield* (yield* ExtensionProviderService).getServicesApi;`
  - `const conn = yield* api.services.ConnectionService.getConnection(username);`
  - scratch skip: `conn.getAuthInfoFields().devHubUsername` (replaces `org.getField(Org.Fields.DEV_HUB_USERNAME)`)
  - live probe: `yield* Effect.tryPromise({ try: () => conn.refreshAuth(), catch: cause => new OrgConnectionCheckError({ cause, username: conn.getUsername() ?? username }) }).pipe(Effect.as('Connected'))` — PRESERVE live network probe. `OrgConnectionCheckError` keeps its purpose (refreshAuth live-probe failure only).
- Error handling — do NOT collapse the 4 getConnection tagged errors into one generic `OrgConnectionCheckError` (error-patterns.md "Anti-Pattern: Generic Error Mapping" — funneling distinct tags through one `cause: Unknown` throws away which failure occurred). Instead keep them distinct to the boundary via the trailing `Effect.fn` pipeable:
  - `Effect.catchTag('OrgConnectionCheckError', ({ cause, username }) => Effect.succeed(getConnectionStatusFromError(cause, username)))` — refreshAuth probe result → status string (unchanged behavior).
  - `Effect.catchTags({ NoTargetOrgConfiguredError, FailedToResolveUsernameError, FailedToCreateAuthInfoError, FailedToCreateConnectionError })` — each handler `err => Effect.succeed(getConnectionStatusFromError(err, username))`. Each error's own `message`/`_tag` reaches the string-matcher (`getConnectionStatusFromError`/`shouldRemoveOrg` match on message: `NamedOrgNotFound`, `NoAuthInfoFound`, etc.), so a bad auth still classifies as `Invalid org: <username>` rather than an opaque generic. No information discarded.
- Update `OrgConnectionCheckError` doc comment: `refreshAuth` live-probe failure (drop the stale "Org.create" wording).
- Remove now-orphaned `Org` import (verify: `Org` only used at L198/203/207 today; `AuthFields`/`AuthInfo`/`AuthRemover`/`OrgAuthorization`/`StateAggregator` stay).
- commit: `refactor(org): migrate determineConnectedStatusForNonScratchOrg to getConnection(username) + conn.refreshAuth - W-23354940`
