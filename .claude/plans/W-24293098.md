# W-24293098 — ban raw number for Duration params

## Context

Type-aware local ESLint rule `local/no-raw-duration`. Call arg or object prop whose contextual type includes `Duration` or `Duration.DurationInput`, and whose value is a numeric literal or other `number`.

Bare `number` in `DurationInput` is milliseconds. Wrap every flagged number with `Duration.millis`.

Skip a declared parameter type of plain `number` or `number | undefined` (`Duration.millis(5000)`). Do not skip a union that merely contains `number`.

## Phases

Enable after site fixes so each commit lints clean. Same PR.
