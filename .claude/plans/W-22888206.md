# W-22888206 — Playwright lint: `no-force-option`

## Context

Enable the installed `eslint-plugin-playwright@2.11.0` rule for the existing Playwright globs. Its action-method detection excludes Node filesystem calls such as `fs.rm(..., { force: true })`.

Current upstream-rule inventory: 69 reports in 32 files. Preserve only justified pointer-obstruction exceptions; remediate readiness failures and replace persistent-overlay clicks with an interaction that does not require pointer actionability.

## Implementation

- Set `playwright/no-force-option: error` in the existing Playwright block in `eslint.config.mjs`; do not create or export a local rule.
- Add an ESLint-config integration test in `packages/eslint-local-rules/test/eslint-config-playwright.test.ts`:
  - ordinary Playwright `{ force: true }` action: 1 report
  - line-level suppression with a Windows Test Explorer tooltip rationale: 0 reports
  - Node `fs.rm(..., { force: true })`: 0 reports

- Update `.claude/skills/playwright-e2e/references/coding-playwright-tests.md` to require that exact narrow suppression and rationale for this exception.
