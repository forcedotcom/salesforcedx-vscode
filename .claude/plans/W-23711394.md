# W-23711394: Migrate ARD log-file commands to Effect command registration

## Context

`packages/salesforcedx-vscode-apex-replay-debugger/src/index.ts` registers 4 Apex Replay Debugger log-file commands directly with `vscode.commands.registerCommand`:

- `extension.replay-debugger.getLogFileName`
- `sf.launch.replay.debugger.logfile`
- `sf.launch.replay.debugger.logfile.path`
- `sf.launch.replay.debugger.last.logfile`

Migrate these registrations to the repository's Effect command-registration service so activation, disposal, and command failures use the Effect runtime. Preserve command IDs, arguments, return values, user prompts, launch behavior, and last-log-file behavior.
