# W-23675160 — Remove unused Apex Testing LSP converter

## Context

- Remove Apex Testing's document-symbol/LSP method-position conversion.
- Use the Test Discovery API's method line and column values, defaulting omitted values to line 1, column 1.
- Remove converter-specific tests and update tree-service coverage for the remaining position path.

## Phases

### 1. Remove the LSP position converter

- Delete `findMethodInSymbols` and `getMethodLocationsFromSymbols` from `packages/salesforcedx-vscode-apex-testing/src/utils/testUtils.ts` and remove imports used only by them.
- Remove the converter call and document-symbol position merge from `packages/salesforcedx-vscode-apex-testing/src/views/apexTestTreeService.ts`; build method positions directly from discovered `line` and `column` values.
- Remove class-level lazy resolution from `packages/salesforcedx-vscode-apex-testing/src/views/orgTestItems.ts` and the class branch from `packages/salesforcedx-vscode-apex-testing/src/views/testController.ts`; class methods remain eagerly created, while suite children remain lazily resolved.
- Remove converter tests from `packages/salesforcedx-vscode-apex-testing/test/jest/utils/testUtils.test.ts`.
- Update `packages/salesforcedx-vscode-apex-testing/test/jest/views/apexTestTreeService.test.ts` expectations and mocks affected by removing document-symbol lookup.
- Remove class-resolution mocks and coverage from `packages/salesforcedx-vscode-apex-testing/test/jest/views/testController.test.ts`.
- Strengthen `packages/salesforcedx-vscode-apex-testing/test/playwright/specs/orgOnlyClassRetrieve.headless.spec.ts` to compare method navigation against the direct Test Discovery API line and column.
- Commit message: `refactor(apex-testing): remove unused LSP position converter`
