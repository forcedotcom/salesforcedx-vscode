# W-24256577 — Split Apex Testing E2E across two orgs

## Context

Windows desktop Apex Testing E2E hits the 60-minute job cap. Setup is about 13 minutes. The test step was killed at spec 8 of 14 after 47 minutes. Ubuntu finishes the same suite in 18.

Ten specs share one non-tracking scratch org (`NON_TRACKING_ORG_ALIAS` / `nonTrackingTestOrg`, `--no-track-source`). Apex test runs serialize on that org. Four specs run every class already in it (`All Tests` / `Test: Run All Tests`), so later runs get slower as classes accumulate.

`playwright.config.web.ts` and `playwright.config.desktop.ts` already set `workers: 1` and `fullyParallel: false`. Keep workers at 1. Do not shard two workers onto one org.

`apexTestSuiteDelete.headless.spec.ts` already uses the tracking org (`MINIMAL_ORG_ALIAS` / `minimalTestOrg`). `clearOnLogout` creates its own org. `noOrgVisibility` and `noProjectVisibility` need no org. Those four are ride-alongs. They are not the split.

## Do not repeat the current head

PR 8239 matrixed `org: non-tracking | minimal` and moved only `apexTestSuiteDelete` onto the tracking org. Non-tracking cells ran `npm run test:desktop -- --ignore=**/apexTestSuiteDelete.headless.spec.ts`. `test:web` and `test:desktop` are wireit scripts whose command is `playwright test`. Playwright test has no `--ignore` option. CI: `error: unknown option '--ignore=**/apexTestSuiteDelete.headless.spec.ts'`. The minimal cells passed a positional spec path and succeeded. `--last-failed` is a real Playwright flag. `--ignore` is not.

Replace that matrix. Both new lanes are non-tracking orgs.

## Phases

### 1. `ci: split Apex Testing E2E onto two non-tracking orgs`

Files: `.github/workflows/apexTestingE2E.yml`, `packages/salesforcedx-vscode-apex-testing/package.json`.

Same shape as metadata's second E2E job (`test:web:conflicts` / `test:desktop:conflicts` in `.github/workflows/metadataE2E.yml`): a wireit script per lane, not a CLI filter passed through `npm run`.

- Job A, org-wide runs. Own scratch org, `--no-track-source`, workers 1. Specs:
  - `runApexTestsCommandPalette.headless.spec.ts`
  - `testExplorer.headless.spec.ts`
  - `clearApexTestResults.headless.spec.ts`
  - `staleTestResultsRestoration.headless.spec.ts`
- Job B, class-scoped runs. Second scratch org, `--no-track-source`, workers 1. Specs:
  - `runApexTestsCodeLens.headless.spec.ts`
  - `apexTestSuite.headless.spec.ts`
  - `runApexTestsFailAndFix.headless.spec.ts` (fixed names `AccountService` / `AccountServiceTest`; first run is expected to fail; must not sit on Job A's org)
  - `codeCoverageColorizer.headless.spec.ts`
  - `inWorkspaceFilter.headless.spec.ts`
  - `orgOnlyClassRetrieve.headless.spec.ts`
- Each lane creates, retries, and deletes only its alias. Try-run, parallel run, and `--last-failed` retry call that lane's script. Desktop Ubuntu still prefixes `xvfb-run -a `.
- Ride-alongs stay on the org they already use. `apexTestSuiteDelete` keeps `minimalTestOrg`. Do not drop it, and do not make the matrix "tracking vs non-tracking".
- Artifact names include the lane (and OS on desktop).
- Each wireit command is `playwright test --config=...` plus a positional spec list. Do not pass `--ignore`.
