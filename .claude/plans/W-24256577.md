# W-24256577 — Split Apex Testing E2E across two orgs

## Context

- `.github/workflows/apexTestingE2E.yml` jobs `e2e-web` + `e2e-desktop` each create both scratch orgs, then run the full suite once (`npm run test:web` / `test:desktop` in `packages/salesforcedx-vscode-apex-testing`).
- Orgs: `NON_TRACKING_ORG_ALIAS` (`nonTrackingTestOrg`, `--no-track-source`) + `MINIMAL_ORG_ALIAS` (`minimalTestOrg`, source tracking). Retry recreates both, then `--last-failed`.
- Specs already pick an org:
  - `setupNonTrackingOrgAndAuth`: `apexTestSuite`, `clearApexTestResults`, `codeCoverageColorizer`, `inWorkspaceFilter`, `orgOnlyClassRetrieve`, `runApexTestsCodeLens`, `runApexTestsCommandPalette`, `runApexTestsFailAndFix`, `staleTestResultsRestoration`, `testExplorer` (all `*.headless.spec.ts`).
  - `setupMinimalOrgAndAuth`: `apexTestSuiteDelete.headless.spec.ts` only (`trackingTest` → `MINIMAL_ORG_ALIAS` on desktop).
  - `setupLogoutTestOrgAndAuth`: `clearOnLogout.headless.spec.ts` (helper creates `LOGOUT_TEST_ORG_ALIAS`; workflow does not).
  - no org setup: `noOrgVisibility.headless.spec.ts`, `noProjectVisibility.headless.spec.ts`.
- Configs stay serial per org: `playwright.config.web.ts` + `playwright.config.desktop.ts` set `workers: 1`, `fullyParallel: false`. Desktop comment in `fixtures/desktopFixtures.ts`: specs share `NON_TRACKING_ORG_ALIAS`.

Split = one CI lane per workflow org. Same specs, same aliases. No third org. No extra workers inside a lane.

## Phases

### 1. `ci: split Apex Testing E2E across non-tracking and minimal orgs`

File: `.github/workflows/apexTestingE2E.yml` only.

- Add matrix key `org` on `e2e-web` + `e2e-desktop`: `non-tracking` | `minimal`. Desktop keeps `os` matrix + ubuntu `xvfb-run -a ` include.
- `non-tracking`: create/delete/recreate only `NON_TRACKING_ORG_ALIAS` with `--no-track-source`. Playwright args: `--ignore=**/apexTestSuiteDelete.headless.spec.ts` (covers non-tracking specs, `clearOnLogout`, `noOrgVisibility`, `noProjectVisibility`).
- `minimal`: create/delete/recreate only `MINIMAL_ORG_ALIAS` (no `--no-track-source`). Playwright args: `apexTestSuiteDelete.headless.spec.ts` (`testDir` is `./specs`).
- Same args on try-run, parallel run, + `--last-failed` retry. Retry recreates that lane's org only.
- Artifact names gain the org lane (`playwright-report-apex-testing-web`, `playwright-test-results-apex-testing-web`, desktop `...-${{ matrix.os }}`).
- Wireit `test:web` / `test:desktop` commands stay; npm args append to `playwright test --config=...`.
