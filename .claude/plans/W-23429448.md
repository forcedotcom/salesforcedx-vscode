# W-23429448 — Fix + enforce `runEffectInsideEffect`

## Context

- Effect LS rule `runEffectInsideEffect`: nested `Effect.run*` inside Effect context. Default severity 💡 (suggestion), auto-fixable.
- 8 findings across 3 packages. Fix all, then promote.
- Enforcement mechanism = ratchet in `config/effect-diagnostics.json` `enforcedRules` (fails on any severity). Precedent: `lazyPromiseInEffectSync`. Plugin declared in `tsconfig.common.json` (no per-rule severity overrides yet). "Promote to error" = append rule name to `enforcedRules`.
- Canonical fix: capture `const runtime = yield* Effect.runtime()` in enclosing gen, use the **matching** `Runtime.run*(runtime)(...)` inside vscode callbacks (`runSync`→`Runtime.runSync`, awaited `runPromise`→`Runtime.runPromise`, `runFork`→`Runtime.runFork`); for direct-in-gen calls, replace `Effect.run*` with `yield*`. Do NOT downgrade sync/awaited calls to fire-and-forget `runFork` — that changes ordering/error-surfacing and opens races (stale reads, out-of-order publishes).
- Existing pattern refs: `packages/salesforcedx-vscode-services/src/core/lifecycleWarningListener.ts:19-22`, `.../vscode/prompts/promptService.ts:222-241`.

- **Method preservation is mandatory.** Each site keeps original execution semantics; only runtime source changes (`Effect.run*` → captured `Runtime.run*(runtime)`). #2/#4 stay `runSync` (subscribers/consumers read fresh, must not race a forked update). #6/#7/#8 stay awaited `runPromise` (cancel handler must actually await the interrupt; offer must complete before the async cb resolves). No site switches to `runFork`.
- #6/#7: capture `const runtime = yield* Effect.runtime()` at top of the `Effect.fn` gen, before `Effect.fork`. The captured `runtime` const is closed over by the `onCancellationRequested` cb; keep `await Runtime.runPromise(runtime)(Fiber.interrupt(deployFiber))` so the fiber is actually interrupted (regression risk: dropping the await → deploy/retrieve hangs on cancel).
- #5 (`registerCommandWithLayer`): its sibling `registerCommandWithRuntime` already models the target (`runtime.runFork`); #5 uses a `Layer` not a runtime, so capture via `Effect.runtime()`/`Runtime.runFork(runtime)` — keeps fork semantics.
- `import * as Runtime from 'effect/Runtime'` where missing.
