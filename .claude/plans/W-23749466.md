# W-23749466: Agent-driven visual QA for VS Code extensions

## Context

- PR 7951 manual QA found misleading URL feedback missed by focused tests
- Goal: agent explores real extension UI from WI context, not scripted steps
- Playwright Electron per ADR 0014; accept native-dialog/external-window limits
- One VS Code session with all 15 executable extensions and disposable Salesforce project
- Agent-neutral MCP stdio server; no OpenCode plugin, CLI, VM, or OS automation
- Packaged VSIX mode is the default; development paths remain available explicitly

## Phases

### Phase 1: Add standalone visual QA package and shared support utilities

- Add private `@salesforce/vscode-visual-qa` package owning VS Code acquisition, extension resolution, settings, launch, readiness, video, console capture, and teardown
- Share only VSIX inventory and redaction utilities with `playwright-vscode-ext`; defer shared Electron launcher decomposition
- Add canonical 15-extension directory list matching `.vscode/launch.json`
- Generate disposable no-org workspace with representative Apex, Aura, LWC, Visualforce, and SOQL files
- Isolated user-data/extensions directories; custom VS Code dialogs/menus retained for Playwright

**Commit:** `feat(playwright): add standalone all-extension QA session - W-23749466`

### Phase 2: Expose MCP observe-act loop

- Add direct `@modelcontextprotocol/sdk` dependency
- MCP executable owns one session over stdio; stdout protocol-only
- Tools: start, observe, act, add finding, status, finish
- Observations: bounded ARIA snapshot, screenshot, active editor/tabs, quick input, dialogs, notifications, status bar
- Actions: click, fill, type, press, command palette, wait; target latest observation refs
- Explicit new/starting/running/stopping/closed states; stale sequence rejection; serial mutation; idempotent finish
- No arbitrary evaluate, shell, unrestricted selector, or filesystem tools

**Files:** `packages/salesforcedx-vscode-visual-qa/src/{mcpServer,controllerService,sessionService,schemas}.ts`, `packages/salesforcedx-vscode-visual-qa/bin/**`, package manifests

**Commit:** `feat(playwright): expose visual QA through MCP - W-23749466`

### Phase 3: Persist evidence and findings

- Record findings immediately with severity, area, steps, expected, actual, confidence, evidence
- Final capture and artifact flush on finish or process signal
- Redact credential shapes before MCP responses and persistence
- Explicit blocked limitation for native dialogs/external windows

**Files:** `packages/salesforcedx-vscode-visual-qa/src/{artifactService,sessionService,schemas}.ts`, shared redaction utility
