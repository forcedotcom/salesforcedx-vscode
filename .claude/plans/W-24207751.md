```typescript
yield* Effect.gen(function* () {
  // …
}).pipe(Effect.catchTags({ /* … */ }))
```

ESLint rule for that shape when the outer generator is `Effect.fn`. Same `Effect` callee test as `isEffectFnCall` in `packages/eslint-local-rules/src/noEffectFnWrapper.ts` (Identifier `Effect`, property `fn` / `gen` / `catchTags`).

## Phases

### 1. Add `local/no-nested-effect-gen-catch-tags`

- `packages/eslint-local-rules/src/noNestedEffectGenCatchTags.ts` — `RuleCreator.withoutDocs`, AST only.
  - Report when an `Effect.fn(...)(function* …)` generator contains `Effect.gen(...)` whose call is the object of `.pipe(…)`, and a `.pipe` argument is `Effect.catchTags(…)`.
  - Nearest generator ancestor of the `Effect.gen` must be that `Effect.fn` callback.
  - Report on the `Effect.gen` call.
- `packages/eslint-local-rules/test/no-nested-effect-gen-catch-tags.test.ts` — `RuleTester`, same harness as `test/no-nested-effect-ternary.test.ts`.
  - Invalid: the shape above, including `catchTags` after other `.pipe` steps.
  - Valid: `Effect.gen` service body (not inside `Effect.fn`); `Effect.gen` inside `Effect.fn` with no `catchTags`; `Effect.catchTags` on a non-`Effect.gen` receiver inside `Effect.fn`.
- Register in `packages/eslint-local-rules/src/index.ts`.
- Document bad/good in `packages/eslint-local-rules/README.md` next to `no-nested-effect-ternary`.
- Note the rule on the recovery row of the quick-reference table in `composition-style.md`.

**Commit:** `feat: flag nested Effect.gen catchTags inside Effect.fn`
