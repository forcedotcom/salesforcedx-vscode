# W-22888211: Playwright `no-skipped-test`

## Context

The shared ESLint config registers `eslint-plugin-playwright` for Playwright files but enables no Playwright rules. Enable `playwright/no-skipped-test` so skipped Playwright tests fail lint instead of silently reducing coverage. Remove the existing violations without rule suppressions or exemptions.

Files:

- `eslint.config.mjs`
- Playwright TypeScript files reported by the new rule under `packages/*/test/playwright/` and `packages/playwright-vscode-ext/`

## Phases

### 1. Enforce the rule and remove existing skipped tests

- Enable `playwright/no-skipped-test` as an error in the existing Playwright ESLint block.
- Run lint to produce the complete violation list.
- Remove each Playwright skip. Keep tests runnable only in their supported Playwright project through the existing project-specific spec, fixture, and config structure rather than runtime skipping.
- Do not add ESLint disables, rule options that permit skips, or replacement skip helpers.

Commit: `chore: enforce no skipped Playwright tests`

- `verification`: run repository lint and the affected Playwright suites from the repository root.
