# W-24209158 — Mute Effect version-mismatch WARN on VS Code extension runtimes

## Context

- Effect emits a WARN when an Effect value's version differs from the executing Runtime's version.
- Suppress that runtime-level warning for VS Code extension runtimes without changing dependency versions or application warning calls.
- Centralize runtime construction in the dependency-independent `packages/vscode-extension-runtime`; use it at the existing extension-host `ManagedRuntime.make` sites in:
  - `packages/salesforcedx-vscode-services/src/index.ts`
  - `packages/salesforcedx-vscode-core/src/services/runtime.ts`
  - `packages/salesforcedx-vscode-apex/src/services/runtime.ts`
  - `packages/salesforcedx-vscode-apex-debugger/src/services/runtime.ts`
  - `packages/salesforcedx-vscode-apex-replay-debugger/src/services/runtime.ts`
  - `packages/salesforcedx-vscode-apex-log/src/services/runtime.ts`
  - `packages/salesforcedx-vscode-apex-testing/src/services/extensionProvider.ts`
  - `packages/salesforcedx-vscode-apex-oas/src/services/extensionProvider.ts`
  - `packages/salesforcedx-vscode-lightning/src/services/extensionProvider.ts`
