# W-24194526 — Replace console.* with Effect.log in Effect packages

## Context

- `salesforcedx-vscode-services` Effect runtime logger: `redactingConsoleLoggerLayer` (`src/index.ts`)
- `console.*` skips logger.
- package `src`: `console.error` → `Effect.logError`, `console.warn` → `Effect.logWarning`, `console.log` → `Effect.log`; same message and error value
- fiber with layer: return `Effect.logError` from `catchAll` (then `resultCallback` effect) or `Effect.tapError` beside `Effect.try` / `tryPromise`
- sync callback: services runtime (`getServicesRuntime` / `yield* Effect.runtime()`), not bare `Effect.runSync(Effect.log(...))`; runtime unset → `Effect.provide(redactingConsoleLoggerLayer)` so the log still runs
- Leave once-only `serverUnreachable` guard, `MetadataRetrieveError` return, export `resultCallback`, channel append on deactivate
