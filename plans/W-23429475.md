- Site: `yield* targetOrgRef.changes.pipe(Stream.as(undefined)).pipe(Stream.mapEffect(…), Stream.changes, Stream.runForEach(…))` — 2 chained `.pipe`s, the first an artifact of ops later appended to an existing `.pipe(Stream.as(undefined))` expression.
- `Stream.as(undefined)` is dead here: `Stream.as` maps every element to a constant (`node_modules/effect/dist/dts/Stream.d.ts:333-340` — `Stream.range(1,5).pipe(Stream.as(null))` → `[null × 5]`), no filtering/timing; the next step `Stream.mapEffect(() => Effect.promise(() => isDefaultOrgSet()))` takes 0 params and ignores the element, and `Stream.changes` sits after it on the mapped booleans. Drop it — 1 flat 3-step pipe, and the reason the chain existed goes away. (Elsewhere `ref.changes.pipe(Stream.as(undefined))` is a real idiom for type-unifying merge inputs, e.g. `packages/salesforcedx-vscode-apex-log/src/statusBar/traceFlagStatusBar.ts:94-96` — untouched.)
- Trial-applied and re-measured: soql LS diagnostics `[]`, `tsc -p packages/salesforcedx-vscode-soql/tsconfig.json` exit 0, prettier clean, eslint 0 errors (3 pre-existing warnings elsewhere in the file), `npx jest test/jest/editor` 11/11 pass. Mechanical.

On PR #7893's branch `0c86d46404` moved the mapping out of the SKILL.md:20 bullet into the new file; its last commit `3d7c297cba` ("chore: docs cleanup") deleted that file and nothing else (`+0/-13`), leaving both links and no target.
