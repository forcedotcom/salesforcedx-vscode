# W-23348768 — Migrate Apex telemetry to Effect spans/logs; drop core TelemetryService

## Context

- Implements ADR-0002 (`packages/salesforcedx-vscode-apex/docs/adr/0002-telemetry-to-effect-spans.md`), which implements repo ADR-0012 (spans-only).
- Retire legacy core event API in `salesforcedx-vscode-apex`: `sendEventData`, `sendException`, `sendExtensionDeactivationEvent`.
- Delete holder `src/telemetry/telemetry.ts` (`TelemetryServiceInterface` + `get/setTelemetryService`) and the `vscodeCoreExtension.exports.services.TelemetryService.getInstance` fetch at `src/index.ts:62-67`.
- Holder consumers (all must migrate before delete):
  - `src/languageServer.ts` — `apexLSPSettings` (L105), `apexLSPError`/LSP_ERR (L134), `apexLSPLog` (L156)
  - `src/index.ts` — deactivation event (L121)
  - `src/languageUtils/languageClientManager.ts` — `apexLSPStartup` (L325), `apexLSPRestart` (L149)
  - `src/languageUtils/index.ts` — `apexTestDiscoveryStart`/`apexTestDiscoveryEnd` (L20/L23)
- Export rules (services observability README): only top-level + command spans reach App Insights/O11y. Nested-fiber data → `annotateRootSpan` (`@salesforce/effect-ext-utils`). `Effect.logDebug/logError` = local-debug only, not event replacement.
- `apexLSPLog` = high-volume, allowlist-gated at `client.onTelemetry`. ADR: do NOT make each event a top-level span (reinstates suppressed volume). Write attrs onto 1 long-lived language-client root span (held Span reference); keep allowlist gate at boundary.
- **Invariant (canonical, ADR)**: exactly ONE live `apex.lsp.client` span per client lifetime — not per-`apexLSPLog`-event, not accumulated across restarts. (Referenced elsewhere below as "the 1-per-lifetime invariant".)
  - Why at risk: `createLanguageServer` — runs on first activation AND every LSP restart (`languageClientManager.ts:260-268` restartTimeout → `createLanguageClient` → `createLanguageServer`). `closeExtensionScope()` — fires ONLY in `deactivate()` (`index.ts:102`, sole call site). Extending the memoized module-level `extensionScope` singleton directly (effect-ext-utils/src/extensionScope.ts:13-17) → each restart's span left unended → N unended root spans flush together at deactivate → invariant violated.
  - Fix: per-client-lifetime child scope (`Scope.fork(extensionScope, …)`); `Scope.close` prior child before forking next — prior span ends/flushes at restart, exactly one live at a time.
- CRITICAL — client span must be genuine trace ROOT (`root: true`), not parented to activation:
  - `annotateRootSpan` — walks `Span.parent` to trace's ultimate root (`annotateRootSpan.ts:13-18`); `withParentSpan(clientSpan)` on a non-root clientSpan writes attrs onto the activation span, not clientSpan.
  - Activation span — closes when `activateEffect` returns (`index.ts:52-101`, `Effect.fn`); Jorje emits `apexLSPLog` for rest of session; writes to an ended span = silent no-op (`@opentelemetry/sdk-trace-base` `Span.setAttribute` returns early once ended).
  - Fix: scoped root span, attrs written to the held `Span` reference directly (Phase 1 below).
- Runtime: `getRuntime()` (`src/services/runtime.ts`) → `ManagedRuntime`. Emit standalone one-shot spans via `getRuntime().runFork(...)` with `root: true` (matches `registerCommand.ts:36-37` — root ensures top-level export, not an orphaned child of activation). Precedent: `languageServerOrphanHandler.ts` (annotateRootSpan, withSpan, Effect.fn).
- Allowlist (`apexLspTelemetryAllowlist.ts`) + its test stay.

## Phases

### Phase 1 — languageServer.ts events → spans/logs
- `apexLSPSettings` (L105): standalone low-volume top-level span via `getRuntime().runFork` — `Effect.withSpan('apex.lsp.settings', { attributes: { maxHeapSize }, root: true })`.
- `apexLSPError`/LSP_ERR (L134): span carrying error (`root: true`, one-shot) + `Effect.logError`; keep `showErrorMessage`.
- `apexLSPLog` (L154-158) — 1 long-lived client span, attrs written to the held Span reference (NOT annotateRootSpan, NOT withParentSpan) — see Context CRITICAL note for why:
  - Resolve the extension scope to a `Scope` VALUE first, then fork a per-client child scope, then extend the scoped span into that child. `getExtensionScope()` is an `Effect.fn` returning `Effect<Scope.CloseableScope>` (extensionScope.ts:15), and `Scope.extend`/`Scope.fork` take a resolved `Scope`, NOT an `Effect<Scope>` (Scope.d.ts:124-140, 153) — so `Scope.extend(getExtensionScope())` does NOT compile. Resolve via `runSync` like every existing entrypoint (`apex-log/src/index.ts:47`, `org/src/index.ts:56` both call `Effect.runSync(getExtensionScope())` before `Scope.extend`):
    - Module-level held handle so restart can end the prior span: `let clientScope: Scope.CloseableScope | undefined;` (single `functional/no-let` disable, mirroring extensionScope.ts:12-13).
    - In `createLanguageServer`, before `client.onTelemetry`:
      ```
      const extScope = getRuntime().runSync(getExtensionScope());
      if (clientScope) getRuntime().runSync(Scope.close(clientScope, Exit.void)); // end/flush prior client span on restart
      clientScope = getRuntime().runSync(Scope.fork(extScope, ExecutionStrategy.sequential));
      const clientSpan = getRuntime().runSync(Effect.makeSpanScoped('apex.lsp.client', { root: true }).pipe(Scope.extend(clientScope)));
      ```
    - `makeSpanScoped` returns the `Tracer.Span`.
    - `root: true` → `findRoot`/`onStart` treat it as top-level → exports.
    - Child `clientScope` closed either on next restart (above) or transitively when `closeExtensionScope()` closes parent on deactivate — either way span ends, exporter ships it. Satisfies 1-per-lifetime invariant (Context).
  - In `onTelemetry`, keep `isApexLspTelemetryAllowed(data.properties)` gate at boundary, then write directly: `Object.entries({ ...data.properties, ...data.measures }).forEach(([k, v]) => clientSpan.attribute(k, v))`.
    - No fork-per-event, no annotateRootSpan — `Span.attribute` mutates held span in place.
    - 1 span, not N (attrs last-write-wins, per ADR).
  - Confirm `Scope.fork`/`Scope.extend`/`makeSpanScoped` shape against `effect-best-practices`. Span: `root: true`, held by reference, ended at restart or scope close — 1-per-lifetime invariant (Context).
- Add imports for the fork/close snippet: `import * as Scope from 'effect/Scope'; import * as Exit from 'effect/Exit'; import * as ExecutionStrategy from 'effect/ExecutionStrategy';` (Scope likely already imported).
- Drop `getTelemetryService` import + both `const telemetryService = getTelemetryService()` (L76, L145).
- Holder still present (index.ts consumers remain) → compiles.
- Commit: `refactor(apex): emit languageServer telemetry as Effect spans - W-23348768`
