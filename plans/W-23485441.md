# W-23485441 — github reporter for inline Playwright CI annotations

## Context

- Goal: Playwright failures show as inline GHA annotations (job log + run summary), no html-artifact download/unzip.
- Today both factories in `packages/playwright-vscode-ext/src/config/`:
  - `createWebConfig.ts:28-30` — CI: `[['html',{open:'never'}],['line'],['junit',{outputFile:'test-results/junit.xml'}]]`
  - `createDesktopConfig.ts:30-32` — same, junit `test-results/junit-desktop.xml`
  - non-CI both: `[['html',{open:'never'}],['list']]`
- Every playwright config in the repo goes through these 2 factories (28 `playwright.config.{web,desktop}.ts` files); no per-package `reporter:` override exists (grep `reporter:` under `packages/**/*.ts` → only the 2 factories).
- `github` is a valid `ReporterDescription` member (`node_modules/playwright/types/test.d.ts:42`); type re-exported `@playwright/test` → `playwright/test` → `./types/test`.
- Coexists with `line` — `GitHubReporter.printsToStdio()` returns `false` (`node_modules/playwright/lib/runner/index.js:3122-3124`), so no duplicate progress stream; playwright injects a fallback reporter only when *no* reporter prints to stdio (`index.js:4776-4777`). Keep `line`.
- Emits GHA workflow commands via `process.stdout.write` unconditionally (`index.js:3095-3101`): `::error file=,line=,col=,title=` per failure, `::warning` per slow file, `::notice title=🎭 Playwright Run Summary`. Paths resolved against `GITHUB_WORKSPACE` (`index.js:3192-3194`) — meaningless off-GHA.
- Gate = `process.env.GITHUB_ACTIONS`, not `CI`:
  - `CI=true` locally is a documented workflow (`createWebConfig.ts` webServer comment: "run with `CI=true`" for a fresh headless server) → would dump raw `::error` noise duplicating `line` output.
  - repo precedent for GHA-only annotation output: `scripts/effect-diagnostics.mjs:91` (`isGithubActions`, emits `::error file=…`), `scripts/check-branch.js:13`.
  - GHA always sets both `CI` and `GITHUB_ACTIONS=true` → CI behavior identical to gating on `CI`.
- Reporter policy duplicated across the 2 factories → extract 1 module, keep internal (not re-exported from `src/index.ts`, so no new published API on `@salesforce/playwright-vscode-ext`).
- No `reportSlowTests` change: defaults are 5 min threshold / max 5 (`index.js:540-543`), so slow-file warning annotations stay rare.
- No workflow changes: annotations need nothing from `.github/workflows/*`; junit/html artifact upload steps stay as-is.
- No ADR conflict; ADR `docs/adr/0014-playwright-over-legacy-e2e.md` only settles playwright-vs-legacy.
