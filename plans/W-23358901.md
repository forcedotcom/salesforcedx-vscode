## Phases

### Phase 1 — replace node:path/node:url in LS, extract + test resolveReference

- `src/visualforceServer.ts`:
  - remove `import * as path from 'node:path'`, `import * as url from 'node:url'` (8-9).
  - extract exported pure fn `resolveReference(workspacePath, documentUri, ref, base?)`; preserve exact legacy semantics (NOT a 1:1 WHATWG swap):
    - **Preserve legacy CONTROL FLOW, not just the base swap.** Legacy was sequential: `if (base) ref = url.resolve(base, ref)`, THEN root-relative+workspacePath check on the (base-resolved) ref, THEN final `url.resolve(document.uri, ref)`. So a base-resolved root-relative ref (`<base href="/assets/">`+`foo.png` → `/assets/foo.png`) must still reach the workspacePath join — a base-first early return would escape to `file:///assets/foo.png` (desktop regression). Fix: compute the root-relative-after-base shape first; if present + workspacePath → `Utils.joinPath(URI.file(workspacePath), ref)` (was `URI.file(path.join(...))`).
    - base, non-root-relative → `new URL(ref, new URL(base, documentUri))` (two-step, NOT `new URL(ref, base)` which throws on a relative `<base href="docs/">`); try/catch falls back to `new URL(ref, documentUri)` so no input regresses vs `url.resolve` (never throws).
    - else → `new URL(ref, documentUri).toString()` (was `url.resolve(document.uri, ref)`).
  - `onDocumentLinks` builds `DocumentContext` calling the extracted fn.
  - `import { URI, Utils } from 'vscode-uri'` (Utils added).
- new jest `test/jest/documentLinks.test.ts`: `resolveReference` cases —
  - **RELATIVE base** (`base='docs/'`, ref='foo.png', documentUri='test://test') → `test://test/docs/foo.png` (mirrors `links.test.ts:128-131`; this is the regression the naive swap would have broken — MUST be present).
  - absolute base (`base='http://www.example.com/page.html'`, ref='foo.png') → `http://www.example.com/foo.png`.
  - root-relative w/ workspacePath (ref='/x/y', no base) → `Utils.joinPath` result.
  - base-resolved root-relative + workspacePath (`base='/assets/'`, ref='foo.png') → workspace-anchored `Utils.joinPath` result, NOT `file:///assets/...` (locks the control-flow regression).
  - doc-relative (ref='foo.png', no base, no workspacePath).
  - memfs:// / web-scheme documentUri.
  - unparseable-base fallback (base not resolvable) → resolves ref against documentUri, does NOT throw.
- commit: `refactor(visualforce): drop node:path/node:url from LS via vscode-uri - W-23358901`
