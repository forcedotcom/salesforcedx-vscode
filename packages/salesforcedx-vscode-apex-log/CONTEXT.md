# salesforcedx-vscode-apex-log Context

Execute anonymous, retrieve logs, manage trace flags.

## Language

**Anonymous Apex**:
Script in language `apex-anon` (`.apex`). Not an Apex class.
_Avoid_: Apex file, anonymous class, `.cls` used as a script

**Execute**:
`sf.anon.apex.execute.document` — CodeLens, command palette, and editor context. Same command.
